# ELOA Dev Team — Página Web

Este repositorio contiene la página web de **ELOA Dev Team**, un grupo de desarrolladores universitarios de Hermosillo, Sonora, México.

La página funciona como un **portafolio en equipo** donde mostramos nuestros proyectos: guías, juegos e ideas, principalmente **juegos para aprender**.

🔗 **Ver en línea:** [eloadev.github.io/proyectos](https://eloadev.github.io/proyects/)

![Página de inicio de ELOA](docs/Inicio/img/01.png)

## Herramientas

| Área | Tecnologías |
|---|---|
| Página web | Astro, HTML, CSS, JavaScript |
| Videojuegos | Unity, C# |
| Otros | Python |
| Publicación | GitHub Pages, GitHub Actions |

## Estructura del repositorio

```
├── .github/workflows/   → Publicación automática en GitHub Pages
├── portafolio-v2/       → Código de la página (Astro)
└── docs/                → Documentación de cada proyecto
```

## Cómo correrlo localmente

```bash
cd portafolio-v2
npm install
npm run dev
```
